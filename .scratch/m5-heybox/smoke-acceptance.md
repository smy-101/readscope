# M5 真网 smoke 清单(04 号票,用户侧)

> 环境:真实网络,无需任何账号(小黑盒源全程匿名)。二进制 `./readscope`(或 `go build ./cmd/readscope` 重编)。
> 对照物:小黑盒 App 或 xiaoheihe.cn 网页版,肉眼比对内容一致即可,不要求逐条相等(推荐流个性化,顺序天然有差)。
> 每步记 ✓/✗;任何与预期不符的字段/行为,截图或抄下状态栏报错,回填到 `.scratch/m5-heybox/issues/04-realnet-smoke-wrapup.md` 的 Comments。

## 0. 准备

- [ ] `sources.toml` 的 `enabled` 列表含 `"heybox"`(新装默认含;手开则加一项)
- [ ] `readscope doctor`:小黑盒行显示「N 圈 · 从未拉取」(或已有圈时的「N 圈 · N 条快照 · 最近拉取 X」),不失败
- [ ] `<配置目录>/heybox.device` 已生成(doctor hint_env 行可查配置目录;此文件装一次终身复用,删了会重生成)

## 1. 加圈 CLI

- [ ] `./readscope heybox add 黑神话`:输出「搜索 "黑神话" 的圈…」后列出候选(编号 · 圈名 · 热度描述)
- [ ] 输入序号:提示「已加圈 …(topic N)—— 重启 readscope 后侧栏可见」;`sources.toml` 里出现 `[[heybox.circles]]` 的 name/topic_id
- [ ] 再加 1–2 个圈(挑你真看的);重复加同一圈提示「已在圈列表中」,文件不动
- [ ] 故意输 `99` 再输 `q`:无效序号重提示,`q` 干净退出且文件不动
- [ ] 重启 readscope:小黑盒源侧栏 = 推荐流 + 新圈(按声明序)
- [ ] 手改兜底:文本编辑器把某个圈挪位/删除,重启后侧栏随之(坏表则 doctor 报错点名该条)

## 2. 推荐流刷新

- [ ] Tab 到小黑盒 → 推荐 F5:约 10 帖/页,元信息有「N 赞 · N 评论」,卡片成列
- [ ] 无广告卡混入(广告无 linkid,列表层应静默丢弃;若见排版异常的「帖子」记下标题)
- [ ] Ctrl+N 翻页:新帖追加、不重复;未读点(●)语义与 RSS/HN 一致,Enter 打开即消,Ctrl+R 可恢复
- [ ] 与 App 首页肉眼同源:同期热帖大体重合(个性化排序允许顺序差异)

## 3. 圈流刷新

- [ ] 侧栏切一个圈 → F5:约 20 帖/页,与 App/网页版该圈页内容一致
- [ ] Ctrl+N 翻页不重复;已读/未读、收藏、未读过滤(F4)与全源同语义

## 4. 五类帖两层详情(各挑一张卡)

- [ ] **纯文本帖**:Enter 开帖,正文全文渲染,`[cube_表情]` 降级为 `[表情]`
- [ ] **多图帖**:正文里图片以 `[图片]` 链接标记出现(不试图画图)
- [ ] **视频帖**:标题 +「视频」标记,可读、不卡;Ctrl+O 跳浏览器可看
- [ ] **文章帖**(长文攻略):正文经排版管线渲染(标题/段落/引用成型,非裸 HTML)
- [ ] **转发帖**:按普通帖可读(本票重点核验项:真样本首次落地——若渲染异常,确认至少降级为标题卡不崩,记样本帖名回填 Comments)
- [ ] 帖层页脚有「N 条评论」;再 Enter 进评论层:根评论成楼(作者 · 赞 N · N 条回复),楼中楼扁平化两层带 @parent
- [ ] Esc 逐层退(评论层 → 帖层 → 列表),各层滚动位置独立;←→ 楼层间移动
- [ ] Ctrl+O 浏览器开当前帖(share_url);Ctrl+Y 复制链接
- [ ] 0 评论帖:页脚「0 条评论」,Enter 提示无评论、零请求;「开过的 0 评论帖」与「从未打开」未读点有区分

## 5. 高热帖读到尽头(100+ 楼)

- [ ] 挑一个 100+ 评论的热帖,评论层 Ctrl+N 连续续拉:状态栏「已加载 N 楼」递增,到服务器总数后提示到底
- [ ] 楼中楼补全:某楼显示「N 条回复」但只见了部分时,自动/进入补页后可见子回复数 ≈ 楼层头数(站方删评允许小差),无重复楼、无丢楼

## 6. 风控(机会性,不强求触发)

- [ ] 若状态栏出现「小黑盒风控/限流,稍后再试(已缓存内容不受影响)」:当次刷新失败但缓存列表/详情照常可读,稍后自愈即算过
- [ ] 全程无需登录任何账号;若见登录引导类报错(非预期),抄状态栏原文回填

## 7. 离线

- [ ] Ctrl+Q 退出 → 断网 → 重进:推荐流/圈流列表即现(缓存先行),开过的帖子正文与评论全部可读
- [ ] 未读状态、收藏在断网下保持

## 8. 收藏快照

- [ ] 帖子卡上 Ctrl+F:F3 收藏列表可见该帖,快照可读(平台删帖不影响本地)

## 9. doctor 与双语终检

- [ ] 拉取过内容后再跑 `readscope doctor`:小黑盒行 =「N 圈 · N 条快照 · 最近拉取 X」(N=圈数,快照数>0,X 是相对时间)
- [ ] `config.toml` 改 `language = "en"` 重启:推荐流标签 "For You"、元信息 "N up · N comments"、楼层提示、doctor 小黑盒行、`heybox add` CLI 文案全部英文,无裸键名(形如 `heybox.recommend`)漏出
- [ ] F1 帮助屏两种语言下键位表完整(Ctrl+N/F4/Ctrl+O/Ctrl+Y 等行齐)
- [ ] 改回 `language = "zh-CN"`

## 10. 收尾

- [ ] 偏差汇总:字段/行为与上述预期不符处,逐条记入 `.scratch/m5-heybox/issues/04-realnet-smoke-wrapup.md` 的 Comments(附帖名/状态栏原文)
- [ ] 转发帖核验结论回填本票 Comments(正常渲染,或确认降级兜底形态)
- [ ] 交回 agent:偏差回补 fixture、勾选 04 号票剩余项,M5 收官
