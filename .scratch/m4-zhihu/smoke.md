# M4 真网 smoke 清单(07 号票,用户侧)

> 环境:真实网络 + 真实知乎账号 cookie(建议先小号)。二进制 `./readscope`(或 `go build ./cmd/readscope` 重编)。
> 每步记 ✓/✗;任何与预期不符的字段/行为,截图或抄下状态栏报错,回填到 07 号票 Comments。

## 0. 准备

- [ ] 浏览器登录 zhihu.com → F12 → 网络 → 刷新 → 任一 zhihu.com 请求 → 复制请求头 Cookie 整行
- [ ] `./readscope doctor`:知乎 cookie 行显示「N 键 · z_c0 ✓」,权限 0600

## 1. 三 feed 刷新(对照网页侧)

- [ ] Tab 到知乎 → 热榜 F5:约 30 行,元信息列有「N 万热度」,排序=热度降序;条目数与 zhihu.com/hold 网页肉眼一致
- [ ] 侧栏切关注 → F5:你关注的人的回答/提问,只见到问题卡(无文章/想法/视频卡);条目与 zhihu.com/follow 网页肉眼一致
- [ ] 侧栏切日报 → F5:当天一期列出;Enter 开一篇,正文全文渲染(首次打开才拉,第二次打开零请求、断网也可读)
- [ ] Ctrl+N:热榜提示「没有更多了」;关注/日报能翻页且不重复、已读状态保持

## 2. 五个问题三层走查(含高热度长回答)

- [ ] 热榜挑 5 个问题,逐个 Enter:问题层 = 标题 + 浏览/回答数 meta + 描述 + 楼层列表(author · 赞 N · N 条评论)
- [ ] 回答层:Enter 进单答全文,←→ 在回答间移动,Esc 逐层退,各层滚动位置独立
- [ ] Ctrl+N(问题层):加载下一页回答;到 answer_count 总数后提示到底
- [ ] 评论层:挑一个高热度长回答(评论 100+),Enter 进评论;根评论成楼、子回复两层带 @parent;长评论线程分页补全(状态栏出现加载,最终评论数 ≈ 楼层头 N 条评论)
- [ ] Ctrl+O:浏览器打开当前问题/回答页;Ctrl+Y 复制链接
- [ ] 404 情形(若遇到已删问题):显示「问题不存在或已删除」,不崩溃

## 2b. 文章卡两层走查(09 号票)

- [ ] 推荐流或关注流里找到一张文章卡(专栏文章,Ctrl+O 应开 zhuanlan.zhihu.com/p/…):Enter 开正文层 = 标题 + 作者 + 排版全文;页脚有「N 条评论」
- [ ] 正文内 Enter → 评论层(根评论成楼、子回复两层带 @parent,与回答评论同观感);Esc 逐层退(评论层 → 正文层 → 列表,无中间层),各层滚动独立
- [ ] Ctrl+N(评论层):先跳已载行、再拉下一页根评论;无评论的文章 Enter 直接提示「无评论」且零请求
- [ ] 慢网络开文章时立刻再按一次 Enter(正文还在加载就进评论层):正文落地后评论自动加载,不得停在「无评论」假屏(09 评审 P1 回归项)
- [ ] Ctrl+O/Ctrl+Y(任一层):开/复制专栏文章页

## 3. Ctrl+U 换号

- [ ] 浏览器换第二个账号(或小号)登录,重新复制 Cookie
- [ ] TUI 内 Ctrl+U → 粘贴 → Enter:状态栏「已保存(N 键,z_c0 ✓)」
- [ ] F5 关注流:列表变成新账号的关注内容(无需重启)
- [ ] 故意粘贴缺 z_c0 的行(如只有 d_c0):拒绝保存,文件不被动

## 4. 拔 cookie 降级

- [ ] 退出 TUI,删除 `<配置目录>/zhihu.cookies`(doctor 可查路径)
- [ ] 重进 TUI:热榜/日报 F5 照常出列表;关注 feed 显示登录引导(未登录 —— Ctrl+U)
- [ ] `readscope doctor`:知乎 cookie 行显示「未配置 —— 匿名模式」
